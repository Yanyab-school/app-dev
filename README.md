# My Favorite Movie

**Cars** is my favorite movie. Cars is a 2006 animated movie made by Pixar and released by Disney. It was directed by John Lasseter. The story takes place in a world where all the characters are cars. The main character is Lightning McQueen, a young race car. He gets lost and ends up in a small town called Radiator Springs. There, he meets other cars like Mater, Sally, and Doc Hudson. As he spends time with them, he learns about friendship and that winning isn’t everything.
